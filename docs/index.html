À essayer

  • Autorisez ou refusez une demande depuis sa vignette, sans ouvrir la session.
  • Relancez la session en erreur en lui répondant depuis sa vignette.
  • Réduisez la fenêtre, puis répondez à une demande depuis le dock.
  • Changez la largeur de la barre : elle montre plus ou moins selon la place.
  • Ouvrez une nouvelle session depuis le catalogue.
  • Passez dans l'onglet d'un autre espace quand il vous montre un losange or.
  • Copiez l'adresse d'un agent en cliquant son label.
  • Créez un raccourci rangé dans un cluster : sa carte se dessine pendant la saisie.
  • Validez le plan que l'orchestrateur vous soumet à la Cantina : rien ne part avant.
  • Auditez la table du chantier, puis arrêtez l'audit et lisez sa rétrospective.
  • Ouvrez le coffre du cluster et révélez un secret : c'est noté au journal.

Les six états

Simulation construite sur la direction artistique de KoA 1.21. Les textes anglais du terminal sont ceux qu'affiche Claude Code ; KoA ne les traduit pas. KoA est une application Windows native (WinUI 3) qui demande WSL2 et Claude Code : dépôt des versions.
