KoA est réduit. Le dock reste au-dessus de vos fenêtres et garde la session la plus urgente à portée de clic.

À essayer

  • Autorisez ou refusez une demande depuis sa vignette, sans ouvrir la session.
  • Relancez la session en erreur en lui répondant depuis sa vignette.
  • Réduisez la fenêtre, puis répondez à une demande depuis le dock.
  • Changez la largeur de la barre : elle montre plus ou moins selon la place.
  • Ouvrez une nouvelle session depuis le catalogue.
  • Copiez l'adresse d'un agent en cliquant son label.

Les six états

Simulation construite sur la direction artistique de KoA 0.30. Les textes anglais du terminal sont ceux qu'affiche Claude Code ; KoA ne les traduit pas. KoA est une application Windows native (WinUI 3) qui demande WSL2 et Claude Code : dépôt des versions.
